# KICBA 雙軌論文索引

更新日期：2026-09-22

本目錄包含兩份回答不同研究問題的論文稿。兩份稿件共享部分研究歷程，但使用不同資料、方法與成功條件，不能將其中一份的結果移作另一份的成功證據。

## 方向 A：選擇性目錄項抑制偵測

[以 eBPF 同名回呼巢狀結構辨識選擇性目錄項抑制](TRACK_A_LOW_FALSE_POSITIVE_ROOTKIT_zh-TW.md)

此方向回答：在不讀取檔名或使用者空間輸出的情況下，能否由回呼函式的控制流程辨識選擇性目錄項抑制？

- 正式資料含 8 次獨立開機、384 批及 7,680 次目錄列舉。
- 提出規則對 96 個抑制批次全部警報，對 288 個控制批次均未警報。
- 召回率、精確率及 F1 均為 100%；三種控制狀態的觀察誤報率均為 0%。
- 13 項預先設定的方法成效規則全部通過。
- 結論只適用於受測 CARAXES 類同名回呼短路。合法選擇性過濾器仍可能觸發，因此警報不是通用 rootkit 或惡意性判決。
- 連續量測的延遲目標未達標；每分鐘一次的週期診斷成本規則通過。

## 方向 B：污染受控線上基準更新

[eBPF 核心時序 rootkit 偵測的污染受控線上基準更新](TRACK_B_SAFE_ONLINE_ADAPTATION_zh-TW.md)

此方向回答：能否讓時序基準適應正常漂移，同時避免把未被偵測到的 rootkit 資料寫入正常基準？

- 正式資料含 5 次獨立開機、500 批校正資料及 1,800 批測試資料。
- 雙分支 W50 的攻擊召回率為 93.75%，未載入誤報率為 0%，負控制誤報率為 1%。
- 攻擊資料更新率為 6.25%，視窗最高攻擊占比為 47.92%。
- 正常負載偏移召回率只有 6.83%，沒有證明自適應視窗改善 rootkit 判斷。
- 15 項預先設定規則中只通過 9 項；此方向屬部分改善與受控負面結果。

## 共同證據邊界

- 早期同步量測因函式呼叫組成及目錄截斷混雜，不作方法成功證據。
- 第一次五開機方法因負控制誤報及成本未達標，保留為正式失敗結果。
- D6-r1 在成效分析前因規格與實作不一致中止；D6-r2 才是線上更新方向的正式結果。
- D7 的結構型方法沒有自適應視窗、正常漂移或污染端點，不能用來宣稱方向 B 已成功。
- 方向 A 首次正式資料稽核因輸入目錄命名規則過寬而停止；修正只建立逐位元相同的正式輸入視圖，沒有更動資料、方法、門檻或成功條件。
- 最高層獨立單位在方向 A 是 8 次開機，在方向 B 是 5 次開機；不能以同一次開機內的大量批次取代獨立重複。
- 方向 A 的零觀察誤報不代表母體誤報率必為零；每一控制狀態的批次層級 Wilson 95% 信賴區間約為 0% 至 3.85%。
- 前人研究與本研究若資料、攻擊、特徵及評估設定不同，只能作方法背景比較，不能以單一數字直接排名。
