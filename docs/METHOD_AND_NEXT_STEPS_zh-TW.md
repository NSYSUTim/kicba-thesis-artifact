更新日期：2026-10-27。此處統整原九次開機主實驗、2026-10-23 完成的兩輪補充確認，以及定稿時的離線核對。目前書面為 [revised33 乾淨版](../paper/cross_layer_directory_entry_consistency_revised33_zhTW.docx)，新增限制與計時說明見[定稿後核對](PAPER_REVIEW_UPDATES_20261027_zh-TW.md)。2026-10-24 的[書面更新對照](PAPER_UPDATE_GUIDE_20261024_zh-TW.md)保留為當時以 revised26 為底的修訂依據。以下以工作名稱區分，不把部分完成當成整個未來研究方向完成。

## 目前比較什麼

比較同一次完整目錄列舉中，核心 filldir64 最外層回傳 true 的項目，與專用單執行緒 C 掃描器反覆呼叫 getdents64 直到回傳 0 所取得的項目。名稱位元組、inode、型態共同構成身分。只計最外層且已接受的呼叫，避免包裝巢狀重複計數及把正常的緩衝區不足重送計入。

控制程式在放行前登記量測執行緒，單執行緒掃描器的 TID 與 PID 相同。兩端同步建立 F=(n,A,B) 與 IBLT，實驗每次都解碼。摘要大小在容量固定時固定，逐項處理時間仍隨項目數增加。順序重排不算身分差異。

指紋決定是否有差異，IBLT 還原識別值、inode、型態，不還原名稱。256 cells／32 個差異是經驗設計目標及八倍預留，不是任何輸入必定解碼成功的界線。公開種子與 FNV 不提供對主動碰撞的密碼學保證，兩總和未證明獨立，也沒有任意多重集合差異的形式漏報上界。

本實作以計數與 XOR 累計 IBLT，解碼從計數為 ±1 且通過校驗的儲存格開始。一端只有兩份 X、另一端為空時，三個位置的內容為零、計數為 2，無法剝離；一端有兩份 X、另一端有兩份 Y，且三個位置相同時，整張差異表歸零，解碼器錯誤回報成功。具體離線反例中的指紋仍不同，但不能據此保證一般輸入不碰撞。正式受測還原使用獨立預期差異核對；執行流程尚未加入解碼結果的指紋回算。

| 狀態 | 輸出與解讀 |
|---|---|
| 量測資料缺少、失效或品質窗口不可靠 | 拒判／無效，不算一致或警報；保留原因，另次量測是新交易 |
| 量測有效、指紋相同 | 這次未觀察到邊界內差異，不是內容必然相等的證明 |
| 指紋不同、解碼旗標為成功 | 差異警報及回報的兩端獨有識別值；旗標本身不保證任意輸入的還原正確，受測結果另經獨立核對 |
| 指紋不同、解碼失敗 | 警報仍成立，標示不能完整定位；部分剝離不當完整差集 |

上述配對降幅使用不含返回探針統計與事件身分查詢的耗時，也是事前指定的採用指標。含查詢時間的追加核對由相同原始紀錄重算，各開機比值中位數為 0.553–0.606，降幅為 39.4%–44.7%。兩種指標均不含 BPF 編譯與附掛；查詢包含 `kprobe_profile` 的統計、`kprobe_events` 的定義與事件 `id`。六個開機各有 10 個主要配對，逐區組相除後才取開機中位數。

上述補充數量都不是原主實驗的額外批次。先導、補充故障與未修改原版對照不混入確認分母。第二輪另有 252 次新增因空間不足未實際注入，包含 240 次量測及 12 次控制；它們不算成功陽性。

原診斷版與合併版的全域 map memlock 約為 7.50 MiB 與 2.60 MiB，256-cell 邏輯摘要仍約 12.02 KiB。前者不是摘要 bytes、整工具實體峰值或流量。候選每筆預留 256 cells、上限 256 執行緒，只實測 16 程序併發，不能宣稱上限已全面驗證。

## 完整性檢查仍有限制

返回 profile 的 missed 是事件全域窗口的讀數；受測 Linux 6.8 的 tracefs 欄位合計內部 kprobe 與返回實例漏失。缺統計、身分錯誤、倒退或漏失均不能當零。入口 perf 探針仍缺乏同等統計，並非所有執行漏失已被排除。

診斷版的 original_valid 含新增收支檢查，不等同未修改原版。另以原判定函式作的 56 次漏失／56 次對照已分開保存，本輪沒有展示舊版錯誤一致被修復。詳見[更正](../phase1/CORRECTIONS_zh-TW.md)。

## 威脅與觀測範圍沒有擴大

仍假設 eBPF、C 掃描器及控制程式未被攻擊者控制，受測模組不依種子或偵測器調整行為。沒有建立種子保密機制、主動碰撞安全證明或外部信任域。

filldir64 之前排除的項目、提早回傳 0 後尚未走訪的項目、只在 libc 等程式庫返回後過濾，以及只向掃描器回傳完整資料，都不是這次已驗證可處理的情形。前後觀測邊界延伸已暫緩。政策過濾仍會警報，惡意性與授權判定沒有加入本方法。

## 外部比較保持原結論

Trace of the Times 仍只有同一 VM 環境分開收集的一次比較。依測試標籤選最佳 F1 門檻的誤報率為 15.20%／27.18%；固定門檻重分析是事後分析。正常批次沒有合法掛接，不能把其誤報原因直接歸因合法掛接；門檻、多重比較、聚合和漂移尚未因果分離。

Decloaker 的既有 180 次隱藏掃描未警報只說明受測完整路徑解析功能與父目錄列舉隱藏的觀測目標不同。此次未重跑上述外部工具，也沒有新增它們的比較結果。
